# LunarTune Desktop

Desktop port of LunarTune, targeting Windows first with Compose Desktop.

This repository is the desktop-focused development line. It keeps LunarTune's Kotlin/Compose
architecture, adapts the portrait UI to landscape, uses a collapsible desktop navigation rail,
and follows VIVI Music Desktop's JVM playback approach. Zuno is used as a reference for desktop
navigation and interaction patterns.

The Android application remains maintained in the main LunarTune repository.
